# Maremonti MX

Modern restaurant website concept developed with React and Vite.

This project explores frontend development for hospitality businesses, combining modern design principles with responsive and accessible user interfaces.

## Technologies

- React
- Vite
- JavaScript
- HTML5
- CSS3

## Features

- Responsive design
- Mobile-first approach
- Modern user interface
- Reusable React components
- Fast frontend development environment

## Purpose

Created as a frontend development project to demonstrate skills in React, JavaScript and modern web development workflows.
